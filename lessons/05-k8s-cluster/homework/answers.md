# תשובות – רכיבי Kubernetes

האנלוגיה: **בית ספר**.

| רכיב | הנהלה / node (כל איפה הוא רץ) | מה הוא עושה, במשפט אחד | אנלוגיה |
|---|---|---|---|
| API server | הנהלה (control plane) | הדלת היחידה לקלאסטר: כל בקשה, מכל רכיב או ממני דרך kubectl, עוברת דרכו. | מזכירות בית הספר: כל פנייה עוברת דרכה ואף אחד לא נכנס ישר לחדר המנהל. |
| etcd | הנהלה (control plane) | מסד נתונים שמחזיק את כל המצב של הקלאסטר: מה אמור לרוץ ומה הגדרנו. | הארכיון עם תיקי התלמידים והמערכת הרשמית של בית הספר. |
| scheduler | הנהלה (control plane) | מחליט על איזה node ירוץ כל pod חדש לפי המשאבים הפנויים. | מי ששובץ תלמידים לכיתות לפי מקום פנוי. |
| controller manager | הנהלה (control plane) | בודק כל הזמן שהמצב בפועל זהה למצב הרצוי, ואם משהו חסר הוא מתקן. | סגן המנהל שסופר נוכחות ודואג שבכל כיתה יהיו כמה שצריך. |
| kubelet | node | רץ על כל node, דואג שה-containers שהוקצו לו אכן רצים, ומדווח על מצבם. | המחנך בכל כיתה שמקבל הוראות מההנהלה ומדווח עליהן. |
| container runtime | node | התוכנה שבפועל מפעילה את ה-containers (למשל containerd). | הציוד והחומרים שבעזרתם מעבירים את השיעור בפועל. |
| kube-proxy | node | מנהל חוקי רשת על ה-node כדי שבקשות ל-Service יגיעו ל-pod הנכון. | השילוט והמוקד הפנימי שמפנה כל מי שמחפש כיתה לכיתה הנכונה. |
| coredns | רץ כ-pod ב-kube-system על ה-nodes (שירות פנימי של הקלאסטר) | מתרגם שמות של Services לכתובות IP בתוך הקלאסטר. | ספר הטלפונים של בית הספר: מחפשים שם ומקבלים מספר. |
